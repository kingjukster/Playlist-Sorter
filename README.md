# Playlist Sorter

Playlist Sorter is a planned local-first system for automatically discovering
useful, overlapping playlists from a music library. It will combine musical
audio, lyrics, metadata, and explicit musical descriptors, then use a
multi-view similarity graph and stability-tested community discovery to group
songs without requiring predefined playlist names.

The project is currently in the planning stage. No implementation, model
weights, datasets, or credentials are included yet.

See [the implementation plan](docs/IMPLEMENTATION_PLAN.md) for the product
scope, architecture, staged build, evaluation protocol, and acceptance gates.
